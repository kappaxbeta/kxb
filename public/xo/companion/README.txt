GRIDBOT COLOUR PALETTES

Eight complete animated GLB models: Blue, Yellow, Pink, Green, Red, Violet, Chrome and Neon.
Each file contains the same robot geometry and five looping clips: Idle, Walk, Attack, Surprise and Dance.
Import a GLB into a glTF-compatible 3D application and select the desired animation clip.
Chrome uses metallic materials. Neon uses emissive cyan, pink and green materials.
